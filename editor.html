private local tool

manage your looks

Import your current looks.json, add or edit outfits, then download an updated looks.json and upload it to GitHub. Use Publish to GitHub to update the live site without downloading or uploading files. Product photos can be uploaded here and embedded in the JSON file (keep them reasonably small).

One-time publishing setup

Enter your GitHub repository and a fine-grained personal access token with Contents: Read and write permission for this repository only. Token stays in this tab memory and is never saved to the site. For security, open the editor locally on your computer when entering a token, not on a shared device.
